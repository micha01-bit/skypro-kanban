# Skypro Kanban

Канбан-доска — учебный проект на курсе SkyPro: SPA-приложение для управления
задачами по аналогии с Trello. Задачи раскладываются по статусам
(например, «Без статуса», «Нужно сделать», «В работе», «Тестирование», «Готово»),
их можно создавать, просматривать в модальном окне и редактировать.

## Дополнительные функциональности

- **Оповещения через React-Toastify** — всплывающие уведомления, в том числе
  при попытке создать задачу с пустым описанием
- **Переключение тёмной / светлой темы** — реализовано через контекст
  `ThemeContext`, выбор темы сохраняется

## Функциональность

- **Регистрация и авторизация** — вход по email и паролю, токен хранится
  в `localStorage` (`userInfo`), сессия сохраняется после перезагрузки
- **Канбан-доска** — задачи сгруппированы по колонкам-статусам, для каждой
  отображается тема, дата и метка
- **Создание задачи** — модальное окно с названием, описанием, сроком
  и меткой
- **Просмотр и редактирование задачи** — модальное окно PopBrowse
- **Защищённые маршруты** — неавторизованный пользователь перенаправляется
  на страницу входа, авторизованный — в основную часть приложения
- **SPA-навигация** — маршрутизация на React Router, модальные страницы
  рендерятся через `Outlet` внутри основной страницы

## Стек технологий

- **React 18** — компонентный подход, хуки (`useState`, контексты)
- **Vite** — сборка и dev-сервер
- **React Router DOM** — маршрутизация
- **React-Toastify** — уведомления
- **Styled Components** — глобальные стили (`GlobalStyle`)
- **Context API** — контексты аутентификации, задач и темы
- **HTML5, CSS3** — вёрстка
- **Backend** — учебный API курса SkyPro (получение и добавление задач)

## Маршруты

| Маршрут        | Страница                        | Доступ              |
| -------------- | ------------------------------- | ------------------- |
| `/login`       | Вход                            | Все                 |
| `/registration`| Регистрация                     | Все                 |
| `/`            | Канбан-доска (лента задач)      | Только авторизованным |
| `/add`         | Создание новой задачи (попап)   | Только авторизованным |
| `/card/:id`    | Просмотр/редактирование задачи  | Только авторизованным |
| `/exit`        | Подтверждение выхода (попап)    | Только авторизованным |
| `*`            | Страница 404                    | Все                 |

## Как запустить

1. Склонируйте репозиторий:
   ```bash
   git clone <адрес-репозитория>
   cd skypro-kanban
   ```
2. Установите зависимости (в корне проекта, где лежит `package.json`):
   ```bash
   npm install
   ```
3. Запустите dev-сервер:
   ```bash
   npm run dev
   ```
   Откроется страница по адресу `http://localhost:5173`.
4. Для продакшн-сборки:
   ```bash
   npm run build
   npm run preview   # локальный просмотр собранной версии
   ```

## Как пользоваться

1. Зарегистрируйтесь или войдите в существующий аккаунт.
2. Создайте задачу кнопкой «Создать задачу»: заполните название, описание,
   срок и метку. Пустое описание вызовет предупреждение Toastify.
3. Перетаскивайте карточки между колонками или меняйте статус при
   редактировании.
4. Кликните по карточке, чтобы открыть подробности задачи.
5. Переключите тему через кнопку в шапке — светлая/тёмная.
6. Выйдите из аккаунта через попап выхода.
